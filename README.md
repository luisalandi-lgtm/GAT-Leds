\# ANSCOVERY - Scheda di Controllo ESP32 (SparkBio)



Codice per la scheda di controllo (SE) del kit ANSCOVERY per la valutazione del Sistema Nervoso Autonomo.



\## Caratteristiche:

\- Microcontrollore: ESP32

\- Uscite Analogiche 0-5V (OUT1 Marker, OUT2 Segnale Continuo)

\- Interfaccia: Display 7 segmenti ELF-3462BB + Barra LED WS2812B
